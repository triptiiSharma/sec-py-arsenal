## Core Concepts

### What Programming Is
Instructions for computers built from basic building blocks:
- Sequential execution
- Conditional logic (if/else)
- Loops (iteration)
- Combining these for complex logic

### Python Basics
- **Python interpreter**: Executes Python code
- **IDLE**: Integrated development environment for writing Python programs
- **Interactive shell**: Test Python commands immediately (REPL)

## Setup Requirements

### Installation
- Download from [python.org](http://python.org/)
- Available for Windows, macOS, Linux
- Check 32-bit vs 64-bit before downloading

### Starting IDLE
- **Windows**: Start menu → Search "IDLE"
- **macOS**: Applications → Python 3.x → IDLE
- **Linux**: Terminal → `idle3`

## Getting Help

### Error Handling
- Read the full error message and traceback
- Search exact error text online (include quotes)
- Check Stack Overflow and documentation

### Asking Questions
When posting to forums (Stack Overflow, r/learnprogramming):
- Explain the goal, not just what you did
- Include full error messages
- Share code via pastebin/gist
- Specify Python version and OS
- Describe what you've already tried
