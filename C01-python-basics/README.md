# Chapter 1: Python Basics

## What This Chapter Covers
- Expressions and operators
- Data types (integers, floats, strings)
- Variables and assignment
- Type conversion between data types
- Basic input/output with `print()` and `input()`

## Core Concepts

### Expressions
Combination of values and operators that evaluate to a single value
- Example: `2 + 3 * 6` evaluates to `20`
- Follow mathematical order of operations (PEMDAS)

### Data Types
- **Integer (int)**: Whole numbers (`-2, 0, 42`)
- **Float**: Decimal numbers (`3.14, -0.5, 42.0`)
- **String (str)**: Text in quotes (`'hello', 'Python'`)

### Operators
- **Math**: `+, -, *, /, //, %, **`
- **String**: `+` (concatenation), `*` (replication)

### Variables
Store values using assignment operator `=`
- Must start with letter or underscore
- Can contain letters, numbers, underscores
- Case-sensitive

### Functions
- `print()`: Display output
- `input()`: Get user input (always returns string)
- `len()`: Get string length
- `str()`, `int()`, `float()`: Convert between types

## Key Takeaways
- Expressions always evaluate to a single value
- Data types determine what operations are valid
- Variables store values for reuse
- Type conversion needed when mixing strings and numbers
- `input()` always returns strings - convert with `int()` or `float()` for math
